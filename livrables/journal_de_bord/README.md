# Journal de bord (point 01)
<!-- onglet: Journal -->

Le journal de bord est tenu sur le site vitrine : [`../site_web/journal.html`](../site_web/journal.html). Une entrée par réunion de suivi, réunion client ou avancée notable, datée (JJ/MM/AAAA) et rattachée aux points du cahier des charges, ajoutée en haut de la liste. Dernière entrée : 20/11/2026 (audit v2.1, étude BET, groupe électrogène, version 2.1).

Les comptes rendus des réunions client suivent le modèle [`../communication/modeles/modele_compte_rendu.docx`](../communication/modeles/modele_compte_rendu.docx) et sont numérotés `RLI-CR-nnn`. L'avancement des 21 points est suivi dans la roadmap (`roadmap/index.html`) ; les audits et leur traitement sont dans [`../audit/`](../audit/README.md).
