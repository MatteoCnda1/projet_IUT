# Journal de bord
<!-- onglet: Journal -->

Le journal de bord est tenu sur le site vitrine : [`../site_web/journal.html`](../site_web/journal.html). Une entrée par réunion de suivi, réunion client ou avancée notable, ajoutée en haut de la liste.

Les comptes rendus des réunions client suivent le modèle [`../communication/modeles/modele_compte_rendu.docx`](../communication/modeles/modele_compte_rendu.docx) et sont numérotés `RLI-CR-nnn`.
